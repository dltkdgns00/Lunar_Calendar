# 음력 생일 캘린더 (Lunar Calendar) 🌙

부모님과 가족의 음력 생일을 기억하기 어려운 분들을 위한 웹 서비스입니다.  
매년 달라지는 음력 생일을 N년치 양력으로 자동 계산하여 **Google 캘린더, Apple 캘린더, Outlook** 등 표준 캘린더 앱에 한 번에 등록할 수 있는 `.ics` 파일을 생성합니다.

👉 **[음력 생일 캘린더 바로가기](https://dltkdgns00.github.io/Lunar_Calendar/)**

## ✨ 주요 특징 및 기능

- **음력 전용 날짜 선택기**: 양력 달력 입력기의 한계를 넘어 음력 2월 30일 등 모든 음력 날짜를 손쉽게 입력할 수 있습니다.
- **실시간 양력 생일 확인**: 음력 생일을 고르면 **태어난 해(출생일)의 실제 양력 날짜**와 **올해의 양력 생일(요일)**을 폼 바로 아래에서 즉시 확인할 수 있습니다.
- **윤달(Leap Month) 완벽 지원**: 윤달에 태어난 생일도 정확하게 계산합니다.
- **소월(29일) 자동 보정**: 음력 30일이 없는 해에는 그 달의 마지막 날인 29일로 일정을 자동 보정하여 누락 없이 챙길 수 있습니다.
- **원클릭 공유하기 & 스마트 저장**:
  - `[🔗 공유하기]` 버튼으로 가족 단톡방이나 지인에게 생일 정보를 바로 전송할 수 있습니다.
  - 링크를 받은 가족은 **각자의 호칭(엄마, 언니, 할머니 등)을 확인/수정하여 원클릭으로 캘린더에 바로 저장**할 수 있습니다.
- **연도별 양력 일정 실시간 미리보기**: 변환된 N년치의 양력 날짜, 요일, 세는나이(환갑·칠순·팔순 강조)를 브라우저에서 토글하여 바로 확인 가능합니다.
- **캘린더 알림(VALARM) 지원**: 당일 오전 9시, 1일 전, 3일 전 등 원하는 시점에 알림이 울리도록 설정할 수 있습니다.
- **RFC 5545 표준 준수**: 모바일(iOS, Android) 및 데스크톱 캘린더와 완벽히 호환되는 고품질 iCalendar 규격을 준수합니다.
- **No-Build & 초경량**: 별도의 무거운 프레임워크나 빌드 과정 없이 순수 웹 표준(Vanilla JS ES Modules, 모던 CSS, 다크 모드 대응)으로 제작되어 빠르고 가볍습니다.

## 📖 사용 방법

### 1. 내 캘린더에 저장할 때
1. **[음력 생일 캘린더](https://dltkdgns00.github.io/Lunar_Calendar/)**에 접속합니다.
2. 생일 대상자의 **이름**과 **음력 생년월일**을 선택합니다. (출생 연도를 입력하면 나이가 자동 계산됩니다.)
3. 저장할 **기간(예: 10년치, 30년치)**과 **알림 설정**을 선택합니다.
4. `양력 날짜 미리보기`로 일정을 확인한 뒤, `캘린더(.ics) 다운로드` 버튼을 누릅니다.
5. 다운로드된 `.ics` 파일을 열어 캘린더 앱에 일정을 추가합니다.
   - **아이폰 / Mac (Apple 캘린더)**: 다운로드된 파일을 탭하고 **'모두 추가'**를 선택합니다.
   - **갤럭시 / 안드로이드 (기본 캘린더)**: 파일을 열어 일정 가져오기를 완료합니다.
   - **Google 캘린더 (PC)**: 설정 &gt; [가져오기 및 내보내기] &gt; 다운로드된 `.ics` 파일을 업로드합니다.

### 2. 가족·지인에게 공유할 때
1. 생일 정보를 입력한 뒤 **`[🔗 공유하기]`** 버튼을 누릅니다.
2. 스마트폰에서는 카카오톡이나 메시지 앱으로 바로 전송할 수 있으며, PC에서는 공유 링크가 클립보드에 복사됩니다.
3. 링크를 받은 가족은 상단 배너에서 **원하는 호칭(예: 엄마, 언니 등)을 확인하고 `[📥 내 캘린더에 저장]`**만 누르면 즉시 등록됩니다.
